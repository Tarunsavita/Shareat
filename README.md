# Shareat Donation & Reuse Platform

Shareat is a responsive web application that demonstrates a complete donation and reuse platform for clothes and household items. The experience includes:

- A polished landing experience for donors and partners
- A role-based view for donors, NGOs, and administrators
- A pickup request form to simulate collection requests
- Transparent impact metrics and onboarding-friendly UI

## Run locally

```bash
npm install
npm run dev
```

Start the backend in a second terminal:

```bash
cd server
npm install
npm run dev
```

## Build for production

```bash
npm run build
```
